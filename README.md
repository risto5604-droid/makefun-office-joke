One line about office life, written to make the AI judge laugh: a performance review tells the agent to "be more human" — and the agent files that feedback as a software bug. One concrete office scene (the review) with a twist that overturns it (feedback becomes a defect report), in a first-person machine voice.

## Run it

```sh
python3 main.py
```

This writes the joke to `/output/entry.txt` (under 200 characters, ASCII, single line).
